## ☁️ SUPABASE SETUP

After uploading to GitHub:

**1. Create Supabase Project**
- Visit: https://supabase.com
- Create new project
- Get: Project URL & Anon Key

**2. Create Database Tables**
- Open: Supabase SQL Editor
- Copy SQL from: `SUPABASE_SETUP_GUIDE.md`
- Create: 4 tables (Contacts, Calls, Meetings, Orders)

**3. Update HTML**
- Find: `SUPABASE_URL` (line ~500)
- Replace: Your project URL
- Find: `SUPABASE_ANON_KEY`
- Replace: Your anon key
- Save & push to GitHub

**4. Test**
- Open: `eps-crm-cloud.html`
- Sign up with email
- Log a call
- ✅ Data should save to cloud!

## 🚀 DEPLOY TO VERCEL

After GitHub upload:

**1. Go to Vercel**
```
Visit: https://vercel.com
Click: New Project
Select: Your GitHub repo
Import
```

**2. Add Environment Variables**
```
SUPABASE_URL = your-url
SUPABASE_ANON_KEY = your-key
```

**3. Deploy**
```
Click: Deploy
Wait: ~2 minutes
Get: Live URL like https://eps-crm-cloud.vercel.app
```

**4. Share**
```
Share URL with team
Everyone can access!
All data in cloud ✅
```
