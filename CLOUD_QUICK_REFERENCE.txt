# EPS CRM CLOUD - QUICK REFERENCE CARD

## 🎯 IN 5 MINUTES

### 1️⃣ Create Supabase Account
- Go to https://supabase.com
- Sign up for free
- Create new project

### 2️⃣ Get Credentials
- Settings → API
- Copy Project URL
- Copy Anon Key

### 3️⃣ Create Tables
- Go to SQL Editor
- Copy-paste all 4 SQL queries from SUPABASE_SETUP_GUIDE.md
- Run each one

### 4️⃣ Update HTML
- Open eps-crm-cloud.html
- Find line 500 with SUPABASE_URL
- Replace 'your-project' with YOUR_PROJECT_ID
- Replace 'your-anon-key' with YOUR_ANON_KEY
- Save file

### 5️⃣ Test
- Open HTML in browser
- Sign up with email
- Log a call
- Check Supabase dashboard
- Done! ✅

## 🎮 HOW TO USE

### Sign Up
1. Email: your@email.com
2. Password: any-secure-password
3. Click "Sign Up"
4. Click "Login"

### Make a Call Log
1. Click "Telecaller"
2. Click "Log Call" tab
3. Fill contact details
4. Click "Save Call"
5. ✅ Saved to cloud!
6. All users see it!

### View Contacts
1. Click "Telecaller"
2. Click "Contacts" tab
3. See all contacts from team
4. Search by name/phone
5. Real-time sync
